## Validated Methods for QRNG Analysis

- **Status**: Valid for sample-limited QRNG data
- **Application**: Use when working with finite-length random number sequences
- **Reference**: Miller, D. A., & Takahashi, Y. (1978)

- **Application**: Detect statistical dependencies in sequential data
- **Use Case**: Verify randomness quality by checking conditional independence
